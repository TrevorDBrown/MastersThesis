# DashAR: An Implementation of Augmented Reality Technology for Automotive Applications

[Published on WKU TopSCHOLAR](https://digitalcommons.wku.edu/theses/3844/)

My thesis explores a proof of concept system, which utilizes modern Augmented Reality technology to visualize automobile data, in virtually real time, via a heads up display, while in operation.

## Thesis Structure

This thesis is structured into chapters:

- Chapter 1: Introduction
- Chapter 2: The historical contexts of Automobile Instrumentation, XR technology, and Heads Up Displays.
- Chapter 3: A design for a specific use case for a HUD on XR technology applied for automobile operation purposes.
- Chapter 4: The development process undertaken for creating a solution for the use case.
- Chapter 5: The release of the system, and results gathered.
- Chapter 6: Encountered dilemmas, potential future works, and conclusions.
