## Thesis Structure

This thesis is structured into chapters:

- Chapter 1: Introduction
- Chapter 2: The historical contexts of XR technology, Human-Computer Interface, and Heads Up Displays.
- Chapter 3: A description of a specific use case for a HUD on XR technology applied for automobile operation purposes.
- Chapter 4: The development process undertaken for creating a solution for the use case.
- Chapter 5: The release of the system, and results gathered.
- Chapter 6: Potential Future Works.
