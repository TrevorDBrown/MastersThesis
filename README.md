## Thesis Structure

This thesis is structured into chapters. The first two chapters discuss the historical contexts of XR technology, Human-Computer Interface, and Heads Up Displays. The third chapter covers a description of a specific use case for a HUD on XR technology applied for automobile operation purposes. The following chapters describe the development process undertaken for creating a solution for the use case, as well as the release of the system, and potential future works.
